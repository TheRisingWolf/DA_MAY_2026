# Загрузка данных из CSV, Excel и JSON

Комплект рассчитан на одну практическую пару продолжительностью 90 минут. Уровень слушателей — начинающий.

## Что входит в комплект

```text
loading_and_integration/
├── 01_loading_csv_xlsx_json_student.ipynb
├── 01_loading_csv_xlsx_json_teacher.ipynb
├── data/
│   └── raw/
│       ├── tickets.csv
│       ├── clients.xlsx
│       └── channels.json
├── outputs/
├── README.md
└── requirements.txt
```

- `01_loading_csv_xlsx_json_student.ipynb` — основная версия для слушателей. В ней есть полный базовый маршрут и отдельное мини-задание.
- `01_loading_csv_xlsx_json_teacher.ipynb` — версия преподавателя с решениями, контрольными значениями и методическими комментариями.
- `data/raw` — готовые учебные данные.
- `outputs` — папка для результатов.

## Быстрый запуск в Google Colab

1. Откройте Google Colab.
2. Загрузите нужный `.ipynb`.
3. Выберите **Среда выполнения → Выполнить все**.
4. Если папка `data/raw` не была загружена, notebook создаст учебные файлы автоматически.
5. После перезапуска среды Colab выполните все ячейки повторно.

Интернет для самой практики не требуется.

## Запуск в VS Code

1. Распакуйте архив.
2. Откройте папку `loading_and_integration` в VS Code.
3. Установите расширения Python и Jupyter.
4. При необходимости установите зависимости:

```bash
python -m pip install -r requirements.txt
```

5. Откройте notebook и выберите Python kernel.
6. Выполните **Run All**.

## Типовые проблемы

### `FileNotFoundError`

Выполните ячейки подготовки путей и резервного создания данных. Проверьте текущую папку через `Path.cwd()`.

### Не открывается Excel

Установите `openpyxl`:

```bash
python -m pip install openpyxl
```

### Ошибка при объединении

Проверьте типы ключей, лишние пробелы и уникальность ключа в справочнике. В notebook для этого предусмотрены отдельные диагностические ячейки.

## Учебный результат

Слушатель проходит полный базовый маршрут:

```text
CSV / XLSX / JSON
        ↓
загрузка в pandas
        ↓
проверка структуры и типов
        ↓
подготовка ключей
        ↓
left merge
        ↓
контроль строк и несовпавших ключей
        ↓
сохранение датамарта
```
