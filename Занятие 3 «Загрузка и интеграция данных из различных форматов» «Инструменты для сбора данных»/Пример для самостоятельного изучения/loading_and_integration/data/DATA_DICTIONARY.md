# Словарь данных

## tickets.csv

Одна строка — одно обращение.

| Поле | Назначение |
|---|---|
| ticket_id | идентификатор обращения |
| created_at | дата и время создания |
| client_id | идентификатор клиента |
| channel_code | код канала обращения |
| category | категория обращения |
| priority | приоритет |
| status | текущий статус |
| resolution_hours | время решения в часах |

## clients.xlsx

Одна строка — один клиент.

| Поле | Назначение |
|---|---|
| client_id | ключ связи |
| client_segment | сегмент клиента |
| city | город |
| registration_date | дата регистрации |

## channels.json

Одна строка — один канал.

| Поле | Назначение |
|---|---|
| channel_code | ключ связи |
| channel_name | название канала |
| is_digital | признак цифрового канала |
