# Словарь учебных данных

## `orders.csv`

Одна строка соответствует одному заказу.

| Поле | Тип | Назначение |
|---|---|---|
| `order_id` | string | Уникальный идентификатор заказа |
| `order_date` | date | Дата заказа |
| `customer_id` | string | Ключ клиента |
| `product_id` | string | Ключ товара |
| `quantity` | integer | Количество единиц товара |
| `discount` | float | Скидка в долях от 0 до 1 |
| `channel` | string | Канал продаж |
| `delivery_days` | integer | Фактический срок доставки в днях; целевая переменная модели |

Учебные особенности: четыре пропуска в `discount` и два повторяющихся `order_id`.

## `products.xlsx`

Лист `products`. Одна строка соответствует одному товару.

| Поле | Тип | Назначение |
|---|---|---|
| `product_id` | string | Уникальный идентификатор товара |
| `product_name` | string | Название товара |
| `category` | string | Категория товара |
| `unit_price` | float | Цена единицы |
| `cost_price` | float | Себестоимость единицы |

## `customers.json`

JSON-массив объектов. Одна запись соответствует одному клиенту.

| Поле | Тип | Назначение |
|---|---|---|
| `customer_id` | string | Уникальный идентификатор клиента |
| `segment` | string | Сегмент клиента |
| `region` | string | Регион |
| `city` | string | Город |
| `registration_date` | date | Дата регистрации |
| `loyalty_level` | string | Уровень лояльности |

Учебная особенность: три пропуска в `segment`.
