# Вводный notebook: загрузка, интеграция и моделирование данных о продажах

Комплект показывает полный базовый сценарий работы с данными:

- импорт библиотек;
- загрузка CSV, XLSX и JSON;
- предварительный анализ качества;
- очистка и интеграция таблиц;
- расчёт показателей продаж;
- обучение модели для оценки срока доставки;
- оценка MAE, RMSE и R²;
- визуализация;
- сохранение и загрузка модели.

## Google Colab

1. Откройте Google Colab.
2. Загрузите `00_intro_sales_data_pipeline_ml.ipynb`.
3. Выполните `Среда выполнения -> Выполнить все`.
4. Если файлы данных не загружены, notebook создаст их автоматически.
5. После перезапуска среды выполните notebook сверху вниз повторно.

## VS Code

1. Откройте папку комплекта в VS Code.
2. Установите расширения Python и Jupyter.
3. Выберите Python kernel.
4. При необходимости выполните `pip install -r requirements.txt`.
5. Откройте notebook и нажмите `Run All`.

## Результаты

После выполнения появятся:

- `outputs/sales_integrated.csv`;
- `outputs/delivery_predictions.csv`;
- `models/delivery_days_model.joblib`.

## Примечание

Данные синтетические и предназначены только для обучения. Notebook использует относительные пути и не содержит рабочих доступов или персональных данных.

## Контрольные результаты

При запуске комплектных данных с `random_state=42` ориентировочные результаты модели:

- MAE: около `0.87` дня;
- RMSE: около `1.08` дня;
- R²: около `0.59`.

Небольшие отличия возможны между версиями библиотек. Главная контрольная точка — notebook выполняется сверху вниз и создаёт модель и два выходных CSV-файла.
