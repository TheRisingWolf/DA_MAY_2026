## Главное правило работы

**Запускайте ячейки строго сверху вниз.**

Одни ячейки создают данные и переменные, а следующие используют их. Если пропустить ячейку или выполнить notebook в случайном порядке, возможны ошибки `NameError`, `FileNotFoundError` и `KeyError`.

При повторном открытии notebook или перезапуске среды рекомендуется использовать:

```text
Runtime / Среда выполнения → Run all / Выполнить всё
```

Не изменяйте исходные ячейки генерации данных, если преподаватель не дал отдельное задание.

## Типовые ошибки

### `FileNotFoundError`

Python не нашёл файл.

В этом notebook файлы создаются автоматически. Вероятная причина — пропущен блок создания данных.

Что делать:

1. вернитесь в начало;
2. выполните все ячейки сверху вниз;
3. проверьте, что папка `data/raw/` создана.

### `NameError`

Переменная ещё не создана.

Что делать:

1. найдите ячейку, где создаётся переменная;
2. выполните её;
3. повторите проблемную ячейку.

### `KeyError`

Не найден столбец таблицы.

Проверьте названия столбцов:

```python
df.columns.tolist()
```

Чаще всего причина — пропущена ячейка, создающая нужный столбец.

### `AssertionError`

Одна из проверок качества не выполнена.

Не отключайте `assert`. Посмотрите текст ошибки и проверьте предыдущие этапы очистки. Такая ошибка означает, что итоговая таблица не соответствует установленному правилу.

### Ошибка при чтении или записи Excel

Установите `openpyxl`:

