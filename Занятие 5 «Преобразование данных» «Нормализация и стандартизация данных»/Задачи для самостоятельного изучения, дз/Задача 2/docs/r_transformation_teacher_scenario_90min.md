# Сценарий преподавателя на 90 минут: преобразование данных в R

## Цель блока

Провести слушателей через полноценную подготовку аналитической витрины в R на уже знакомом кейсе продаж.

Главный акцент: не учить R абстрактно, а показать перенос производственной логики из Python в R.

## Ожидаемый результат

К концу блока у слушателей должны появиться файлы:

- `outputs/r_sales_prepared_with_quality_flags.csv`;
- `outputs/r_sales_datamart.csv`;
- `outputs/r_report_by_region_channel.csv`;
- `outputs/r_transformation_log.csv`;
- `outputs/r_normalization_decision.md`.

## Ключевые объяснения

### Почему снова тот же кейс

Слушателям важно увидеть, что инструмент меняется, а производственная логика остается той же: данные нужно проверить, привести к единому виду, соединить, рассчитать показатели и сохранить результат.

### Где чаще всего возникают ошибки

- RStudio открыт не из `.Rproj`, поэтому файлы не найдены.
- Не установлены `tidyverse`, `readxl`, `jsonlite`.
- Слушатель запускает только середину скрипта, не создав предыдущие объекты.
- Даты не преобразуются из-за неверного формата.
- `left_join` дает больше строк, если не удалить дубли в справочнике.
- Итоговая выручка не совпадает из-за неполного набора исключающих флагов.
