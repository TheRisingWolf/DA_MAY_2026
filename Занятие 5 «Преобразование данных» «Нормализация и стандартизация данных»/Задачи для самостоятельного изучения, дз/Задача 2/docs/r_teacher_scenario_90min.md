# Сценарий преподавателя: установка R и первый запуск кейса

## Цель блока

Провести слушателей через первый запуск R/RStudio и показать, что R решает знакомую аналитическую задачу: входной аудит данных перед отчётом.

## Результат блока

К концу 90 минут слушатель должен:

- открыть RStudio;
- проверить версию R;
- открыть проект через `.Rproj`;
- установить или проверить пакеты;
- загрузить `sales.csv`, `products.xlsx`, `clients.csv`, `regions.json`;
- получить первые диагностические таблицы;
- сохранить результат в `outputs`.

## Акценты преподавателя

1. R — не замена Python в курсе, а дополнительный инструмент аналитика.
2. Важно не синтаксическое отличие, а перенос рабочей логики: источник → проверка → проблема → решение.
3. Начинающим не нужно сразу знать весь R. Достаточно уверенно запускать проект, читать данные и понимать результат.
4. `.Rproj` снижает риск ошибки с рабочей папкой.
5. `install.packages()` устанавливает пакет, а `library()` подключает его в текущей сессии.

## Резервные сценарии

| Риск | Что сделать |
|---|---|
| нет прав на установку R | показать демонстрацию преподавателя, дать скрипты для самостоятельного запуска позже |
| RStudio не видит R | проверить порядок установки: сначала R, затем RStudio |
| пакет не устанавливается | использовать демонстрационный запуск преподавателя и сохранить синтаксис для повторения |
| файлы не найдены | открыть `.Rproj` и повторить `03_r_check_environment.R` |
| группа сильно отстаёт | выполнить только проверку среды и загрузку `sales.csv` |

## Мост к следующему блоку
