# Рубрика мини-защиты итогового результата

| Критерий | Что проверяется | Баллы |
|---|---|---:|
| Понимание рабочей задачи | Слушатель объясняет, зачем выполнялся аудит и подготовка витрины | 2 |
| Работа с качеством данных | Названы основные проблемы: дубли, даты, бизнес-правила, ключи | 2 |
| Преобразование данных | Объяснены нормализация, стандартизация и исключение критичных строк | 2 |
| Проверка результата | Показаны контрольные значения и сверка Python/R | 2 |
| Аналитический вывод | Есть ограничение анализа и решение о пригодности данных | 2 |

## Шкала

- 9–10 баллов: результат готов, слушатель уверенно объясняет логику.
- 7–8 баллов: результат в целом готов, есть небольшие пробелы в объяснении.
- 5–6 баллов: выполнена техническая часть, но вывод слабый или неполный.
- 0–4 балла: результат не готов или слушатель не может объяснить выполненные действия.
