# Чек-лист самопроверки

Перед сдачей отметьте каждый пункт.

## Данные и код

- [ ] Notebook выполняется сверху вниз без ошибок.
- [ ] Используются относительные пути.
- [ ] Исходные файлы не перезаписаны.
- [ ] Проверены типы, пропуски и дубликаты.
- [ ] Дубликаты пользователей и активности обработаны осознанно.
- [ ] Денежные значения и оценки преобразованы в числа.
- [ ] После `melt` описана гранулярность таблицы.
- [ ] После `pivot_table` одна строка соответствует пользователю и месяцу.
- [ ] После каждого `merge` проверено число строк и состояние `_merge`.

## Признаки и масштабирование

- [ ] Созданы все обязательные производные признаки.
- [ ] Идентификаторы и даты не переданы в scaler.
- [ ] Выполнены Min–Max, StandardScaler и RobustScaler.
- [ ] Проверены статистики после преобразований.
- [ ] Выбор метода для данных с выбросами объяснён.
- [ ] Preprocessor обучен только на исторических данных.
- [ ] Новая выгрузка проходит только через `transform`.
- [ ] Неизвестные категории не вызывают ошибку.

## Результаты

- [ ] Итоговые CSV-файлы сохранены.
- [ ] Создано не менее четырёх графиков.
- [ ] У графиков есть названия и подписи осей.
- [ ] Вывод содержит конкретные показатели.
- [ ] Указано хотя бы одно ограничение анализа.
- [ ] Приложена инструкция запуска.
