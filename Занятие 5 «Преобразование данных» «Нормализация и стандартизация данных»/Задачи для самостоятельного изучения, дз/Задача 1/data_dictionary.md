# Словарь данных

## `users.csv`

| Поле | Тип после обработки | Назначение |
|---|---|---|
| `user_id` | string | Уникальный идентификатор пользователя |
| `registration_date` | datetime | Дата регистрации |
| `region` | category/string | Регион после нормализации написания |
| `segment` | category/string | Пользовательский сегмент |
| `tariff_id` | string | Ключ тарифа |

В файле намеренно присутствуют несколько дубликатов, варианты регистра/пробелов и пропуски `tariff_id`.

## `monthly_activity_wide.csv`

Одна строка описывает пользователя, а столбцы содержат пять показателей за январь–март 2026 года.

| Префикс | Смысл |
|---|---|
| `sessions_` | Число сессий |
| `minutes_` | Минуты использования |
| `spend_` | Расходы пользователя, сохранённые текстом |
| `support_calls_` | Число обращений в поддержку |
| `satisfaction_` | Оценка удовлетворённости, сохранённая текстом |

В файле есть пропуски, дубликаты и несколько экстремальных значений.

## `tariffs.csv`

| Поле | Тип после обработки | Назначение |
|---|---|---|
| `tariff_id` | string | Уникальный ключ тарифа |
| `tariff_name` | string | Название тарифа |
| `monthly_fee` | float | Абонентская плата |
| `included_minutes` | integer | Включённые минуты |
| `included_sessions` | integer | Ориентир по числу сессий |

## `new_users.csv`

Новая выгрузка уровня «пользователь × месяц». Она содержит те же признаки, которые используются в preprocessing, а также новые категории `северный округ` и `vip`, пропуски и один выраженный выброс расходов.

## Производные признаки

| Поле | Расчёт и смысл |
|---|---|
| `tenure_days` | Разница между месяцем наблюдения и датой регистрации |
| `minutes_per_session` | Минуты / число сессий |
| `over_limit_minutes` | Превышение включённых минут, не меньше нуля |
| `spend_vs_fee` | Фактические расходы минус абонентская плата |
| `avg_sessions_3m` | Среднее число сессий пользователя за три месяца |
| `low_satisfaction` | 1, если оценка ниже 3.5 |
| `high_support_load` | 1, если обращений в поддержку не меньше 3 |

## Гранулярность таблиц

- `users.csv`: один пользователь;
- `monthly_activity_wide.csv`: один пользователь, несколько месяцев в столбцах;
- `user_activity_long.csv`: один пользователь × один месяц;
- `user_activity_datamart.csv`: один пользователь × один месяц с характеристиками и признаками;
- `segment_tariff_summary.csv`: один сегмент × один тариф.
