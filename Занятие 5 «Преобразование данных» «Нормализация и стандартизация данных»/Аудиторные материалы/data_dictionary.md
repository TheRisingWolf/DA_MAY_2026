# Словарь данных

## Источник

Файл: `MoviesOnStreamingPlatforms.csv`  
Источник: <https://github.com/Swapnajacontribution/Datasets/blob/main/MoviesOnStreamingPlatforms.csv>

Зафиксированная учебная копия содержит **9515 строк и 11 столбцов**.

## Гранулярность исходной таблицы

**Одна строка — один фильм.**

Платформенные поля являются независимыми бинарными признаками. Фильм может иметь значение 1 одновременно в нескольких столбцах, поэтому сумма платформенных флагов по таблице превышает количество фильмов.

---

# 1. Исходные поля

| Поле | Исходный тип | Назначение | Пример | Качество и действие |
|---|---|---|---|---|
| `Unnamed: 0` | integer | Технический индекс, записанный в CSV | `0` | Не несёт аналитического смысла, удаляется |
| `ID` | integer | Уникальный идентификатор фильма | `1` | Переименовывается в `movie_id`; не масштабируется |
| `Title` | string/object | Название фильма | `The Irishman` | Переименовывается в `title`; используется для идентификации и расчёта длины названия |
| `Year` | integer | Год выпуска | `2019` | Переименовывается в `release_year`, приводится к nullable `Int64` |
| `Age` | string/object | Возрастная маркировка | `18+`, `7+`, `all` | 4177 пропусков; очищается, `all → 0+`, пропуски → `unknown` |
| `Rotten Tomatoes` | string/object | Рейтинг в формате «балл/100» | `98/100` | 7 пропусков; суффикс `/100` удаляется, поле становится числовым `rating_score` |
| `Netflix` | integer 0/1 | Наличие на Netflix | `1` | Содержательный бинарный признак |
| `Hulu` | integer 0/1 | Наличие на Hulu | `0` | Содержательный бинарный признак |
| `Prime Video` | integer 0/1 | Наличие на Prime Video | `0` | В коде временно переименовывается в `Prime_Video` |
| `Disney+` | integer 0/1 | Наличие на Disney+ | `0` | В коде временно переименовывается в `Disney_Plus` |
| `Type` | integer | Технический код типа | `0` | В наборе имеет одно значение, не даёт аналитического разделения; переименовывается в `type_code` и не используется как количественный признак |

## Контроль качества исходных полей

- `ID` уникален для всех 9515 строк.
- `Age` содержит пять наблюдаемых непустых значений: `all`, `7+`, `13+`, `16+`, `18+`.
- `Rotten Tomatoes` хранится как текст, хотя по смыслу является числовой шкалой.
- Столбцы платформ должны содержать только 0 и 1.
- `Type` константен и не подходит для группировки или масштабирования.

# 2. Поля подготовленной таблицы `movies_clean.csv`

Гранулярность: **одна строка — один фильм**.

| Поле | Тип после подготовки | Правило формирования | Интерпретация |
|---|---|---|---|
| `movie_id` | integer | из `ID` | уникальный технический ключ фильма |
| `title` | string | из `Title` | название фильма |
| `release_year` | nullable integer | числовое преобразование `Year` | год выпуска |
| `age_rating` | string | очистка `Age`; `all → 0+`; пропуски → `unknown` | нормализованная возрастная маркировка |
| `rating_score` | float | удаление `/100`, `pd.to_numeric(..., errors='coerce')` | рейтинг от 0 до 100 |
| `Netflix` | integer 0/1 | без изменения | наличие фильма на Netflix |
| `Hulu` | integer 0/1 | без изменения | наличие фильма на Hulu |
| `Prime_Video` | integer 0/1 | из `Prime Video` | наличие на Prime Video |
| `Disney_Plus` | integer 0/1 | из `Disney+` | наличие на Disney+ |
| `type_code` | integer | из `Type` | техническое поле, не используется как измерение |
| `movie_age` | float | `2026 - release_year` | возраст фильма относительно фиксированного опорного 2026 года |
| `decade` | nullable integer | `(release_year // 10) * 10` | десятилетие выпуска: 1990, 2000, 2010 и т. д. |
| `title_length` | nullable integer | число символов в `title` | длина названия фильма |
| `platform_count` | integer | сумма четырёх платформенных флагов | количество платформ, на которых доступен фильм |
| `availability_group` | string | `multi_platform`, если `platform_count > 1`, иначе `single_platform` | укрупнённый тип доступности |
| `rating_band` | string | интервалы рейтинга | категориальная группа рейтинга |
| `age_min` | float | словарь возрастной маркировки | минимальный возраст; для `unknown` остаётся пропуск |

## Границы `rating_band`

| Значение `rating_score` | `rating_band` |
|---:|---|
| 0–49 | `низкий` |
| 50–64 | `средний` |
| 65–79 | `высокий` |
| 80–100 | `очень высокий` |

## Преобразование возрастной маркировки

| `age_rating` | `age_min` |
|---|---:|
| `0+` | 0 |
| `7+` | 7 |
| `13+` | 13 |
| `16+` | 16 |
| `18+` | 18 |
| `unknown` | пропуск (`NaN`) |

Пропуск не заменяется нулём: отсутствие сведений о маркировке не означает отсутствие возрастных ограничений.

# 3. Длинная таблица `movies_long.csv`

Гранулярность: **одна строка — одна фактическая связь фильма с платформой**.

После `melt` четыре платформенных столбца превращаются в два поля:

| Поле | Тип | Назначение |
|---|---|---|
| `platform` | string | название платформы: Netflix, Hulu, Prime Video или Disney+ |
| `available` | integer | флаг доступности; после фильтрации в таблице остаётся только значение 1 |

Все остальные поля фильма повторяются для каждой платформы, на которой фильм доступен.

Контрольный размер: **9777 строк**.

Это больше 9515, потому что часть фильмов присутствует более чем на одной платформе.

# 4. Справочник платформ `platforms_reference.csv`

Гранулярность: **одна строка — одна платформа**.

| Поле | Назначение |
|---|---|
| `platform` | ключ соединения с длинной таблицей |
| `platform_code` | короткий код платформы |
| `reporting_order` | порядок платформы в отчётах |

Ключ `platform` должен быть уникальным. Соединение выполняется как `many_to_one`.

# 5. Справочник возрастных категорий `age_rating_reference.csv`

Гранулярность: **одна строка — одна нормализованная возрастная категория**.

| Поле | Назначение |
|---|---|
| `age_rating` | ключ соединения |
| `minimum_age` | числовой возрастной порог |
| `audience_group` | укрупнённое человекочитаемое описание аудитории |

Справочник включает категорию `unknown`, чтобы строки без исходной маркировки не терялись при соединении.

# 6. Аналитическая витрина `movies_datamart.csv`

Гранулярность: **платформа × десятилетие × возрастная маркировка**.

Контрольный размер: **167 строк**.

| Поле | Назначение | Правило расчёта |
|---|---|---|
| `platform` | платформа | измерение |
| `platform_code` | короткий код | из справочника |
| `reporting_order` | порядок в отчёте | из справочника |
| `decade` | десятилетие выпуска | измерение |
| `age_rating` | возрастная маркировка | измерение |
| `movie_count` | число уникальных фильмов | `nunique(movie_id)` |
| `mean_rating` | средний рейтинг | среднее `rating_score` |
| `median_rating` | медианный рейтинг | медиана `rating_score` |
| `mean_movie_age` | средний возраст фильмов | среднее `movie_age` |
| `high_rating_share` | доля фильмов с высоким рейтингом | доля строк, где `rating_score >= 80` |

Важно: `high_rating_share` хранится как доля от 0 до 1. Для отображения в процентах значение умножается на 100 либо форматируется как процент.

# 7. Масштабируемые признаки

В третьей паре используются:

| Признак | Почему выбран | Особенность |
|---|---|---|
| `rating_score` | количественная шкала 0–100 | мало пропусков |
| `movie_age` | числовой возраст фильма | содержит большой диапазон и крайние значения |
| `title_length` | длина названия | другая единица измерения |
| `platform_count` | количество платформ | дискретный признак 1–4 |
| `age_min` | минимальный возраст | содержит пропуски из-за `unknown` |

Для технического сравнения scaler-объектов пропуски заполняются медианой. Это учебный выбор, а не универсальное бизнес-правило.

## Поля, которые не нужно автоматически масштабировать

- `movie_id` — идентификатор;
- `release_year` — в текущем кейсе из него уже создан `movie_age`;
- `decade` — категориальный временной бакет;
- платформенные 0/1-флаги — уже находятся в единой бинарной шкале;
- `type_code` — константное техническое поле;
- one-hot поля — уже бинарные.

# 9. Preprocessing-матрицы

## Разделение

- историческая часть: `release_year <= 2019`, **8326 строк**;
- новая часть: `release_year >= 2020`, **1189 строк**.

## Входные признаки pipeline

Числовые:

- `rating_score`;
- `movie_age`;
- `title_length`;
- `platform_count`.

Категориальные:

- `age_rating`;
- `availability_group`.

## Выходные поля

В зависимости от версии scikit-learn названия могут иметь префиксы:

```text
numeric__rating_score
numeric__movie_age
categorical__age_rating_0+
categorical__availability_group_multi_platform
```

Обе итоговые матрицы должны иметь одинаковый набор и порядок признаков. На новой части применяется только `transform` уже обученного pipeline.

---

# 10. Контрольные бизнес- и технические правила

1. `movie_id` уникален в таблице уровня фильма.
2. `rating_score` находится между 0 и 100 либо является пропуском.
3. `platform_count` находится между 1 и 4.
4. `available` в отфильтрованной длинной таблице равно 1.
5. Число строк после `merge` со справочником платформ не изменяется.
6. Ключи справочников уникальны.
7. После `stack → unstack` значения сводной матрицы сохраняются.
8. Историческая и новая preprocessing-матрицы имеют одинаковое число столбцов.
9. Новые данные не участвуют в `fit`.
10. Исходный CSV остаётся неизменным.
