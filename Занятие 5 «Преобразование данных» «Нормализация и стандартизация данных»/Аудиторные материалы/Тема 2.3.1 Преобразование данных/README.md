# Преобразование типов и изменение формы данных

Откройте `notebooks/student_practice.ipynb` или `teacher_solution.ipynb`.

Исходные данные: `data/raw/MoviesOnStreamingPlatforms.csv`.

Результаты сохраняются в `data/processed` и `outputs`.

Основные операции: преобразование типов, создание признаков, `melt`, `pivot`, визуальная диагностика.
