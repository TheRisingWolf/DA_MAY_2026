# Преобразование, нормализация и стандартизация данных

Практический комплект рассчитан на **четыре пары по 90 минут** и построен как единый сквозной кейс: от исходного CSV-файла до аналитической витрины и воспроизводимого конвейера подготовки признаков.

Все части используют один набор данных — каталог фильмов на стриминговых платформах:

- источник: [MoviesOnStreamingPlatforms.csv](https://github.com/Swapnajacontribution/Datasets/blob/main/MoviesOnStreamingPlatforms.csv);
- одна строка исходной таблицы описывает один фильм;
- четыре бинарных поля показывают наличие фильма на Netflix, Hulu, Prime Video и Disney+;
- зафиксированная копия в комплекте содержит 9515 строк и 11 исходных столбцов.

## Учебный результат

После прохождения четырёх пар слушатель сможет:

1. диагностировать структуру и качество табличных данных;
2. преобразовывать текстовые значения в числовые и категориальные признаки;
3. создавать производные признаки с понятным аналитическим смыслом;
4. переводить таблицу между широким и длинным форматами;
5. применять `groupby`, `agg`, `pivot_table`, `stack`, `unstack` и `merge`;
6. собирать аналитическую витрину с заданной гранулярностью;
7. различать Min–Max-преобразование, Z-стандартизацию, робастное масштабирование и нормализацию строк;
8. корректно использовать `fit`, `transform` и `fit_transform`;
9. обрабатывать числовые и категориальные признаки единым `ColumnTransformer`/`Pipeline`;
10. сохранять подготовленные таблицы, графики и обученный preprocessing-объект.

В каждом тематическом каталоге используются одинаковые правила:

- `data/raw` — исходные или контрольные входные данные;
- `data/processed` — подготовленные итоговые таблицы;
- `notebooks` — notebook слушателя и полное решение;
- `outputs` — графики, диагностические таблицы и сохранённые объекты;
- `requirements.txt` — зависимости для локального запуска.

## Порядок прохождения

| Пара | Содержание | Основной notebook | Ключевой результат |
|---:|---|---|---|
| 1 | Преобразование типов, создание признаков, `melt`, `pivot` | `student_practice.ipynb` в каталоге преобразования данных | `movies_clean.csv`, `movies_long.csv` |

## Какой notebook открывать

- Слушателю рекомендуется начинать с `notebooks/student_practice.ipynb`.
- `notebooks/teacher_solution.ipynb` содержит полное решение и используется преподавателем для демонстрации, проверки и восстановления группы после технической задержки.
- Если оба файла доступны в публичном репозитории, сначала выполните задания в студенческой версии и обращайтесь к решению только после собственной попытки или по указанию преподавателя.

## Быстрый запуск в VS Code

### 1. Подготовьте программное окружение

Установите:

- Python 3.10 или новее;
- Visual Studio Code;
- расширения **Python** и **Jupyter** для VS Code.

Откройте терминал в каталоге выбранной пары и выполните:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Активация в Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 2. Откройте notebook

1. Откройте в VS Code **весь каталог пары**, а не только отдельный `.ipynb`.
2. Откройте `notebooks/student_practice.ipynb`.
3. В правом верхнем углу выберите kernel созданного окружения `.venv`.
4. Выполните команду **Restart Kernel and Run All Cells** либо запустите ячейки сверху вниз.

VS Code поддерживает выбор kernel для notebook через Kernel Picker; подробности приведены в официальной документации: <https://code.visualstudio.com/docs/datascience/jupyter-kernel-management>.

## Быстрый запуск в Google Colab

Самый устойчивый вариант — загрузить архив выбранной пары целиком.

1. Скачайте или заархивируйте каталог пары.
2. Откройте Google Colab.
3. Загрузите ZIP в `/content` через панель Files.
4. Распакуйте архив:

```python
from pathlib import Path
import zipfile

archive_path = Path('/content/название_архива.zip')
target_dir = Path('/content/practice')

with zipfile.ZipFile(archive_path) as archive:
    archive.extractall(target_dir)

print('Материалы распакованы в:', target_dir)
```

5. Откройте notebook из распакованной папки или загрузите `.ipynb` отдельно.
6. Выполните ячейки сверху вниз.

Notebook ищет файл `data/raw/MoviesOnStreamingPlatforms.csv` относительно текущей папки, родительских каталогов и типовой папки `/content`. После перезапуска среды Colab загруженные локальные файлы могут исчезнуть, поэтому архив потребуется загрузить повторно.

## Правила работы

1. Не изменяйте исходный файл в `data/raw`.
2. Не переносите notebook отдельно от папки `data`, если не планируете вручную загружать данные.
3. Всегда выполняйте notebook сверху вниз после перезапуска kernel.
4. До построения вывода проверяйте `shape`, типы, пропуски и контрольные `assert`.
5. Сохраняйте результаты только в `data/processed` и `outputs`.
6. Графики в этом комплекте используются как диагностика преобразований, а не как отдельный полноценный курс по визуализации.
7. Масштабирование не удаляет выбросы и не делает распределение автоматически нормальным.
8. Параметры преобразований для новых данных должны вычисляться на исторической части, а к новой части применяется только `transform`.
